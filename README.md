# Komentář k zákonu č. 335/2020 Sb., o mezinárodní spolupráci při řešení daňových sporů v Evropské unii

Otevřený komentář k zákonu o mezinárodní spolupráci při řešení daňových sporů v EU — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; harmonizovaný postup podle směrnice 2017/1852, stížnost, postup vzájemné dohody, poradní komise a komise pro alternativní řešení sporů, nezávislé osoby, konečné rozhodnutí a stanovení daně.

Konsolidované znění: dokument e-Sbírky `SB-2020-00335_2020-09-15`.
